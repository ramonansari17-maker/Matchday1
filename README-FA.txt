# Matchday PWA 3.4

این بسته برای تبدیل Matchday به وب‌اپ قابل نصب روی گوشی آماده شده است.

## انتشار
1. فایل‌های داخل این پوشه را در ریشهٔ مخزن GitHub Pages بارگذاری کن (به‌ویژه `index.html`، `manifest.webmanifest`، `sw.js` و آیکون‌ها).
2. سایت باید با HTTPS باز شود؛ GitHub Pages این را فراهم می‌کند. بازکردن مستقیم فایل HTML از حافظهٔ گوشی، نصب PWA و Service Worker را فعال نمی‌کند.
3. لینک سایت را در Chrome اندروید باز کن. دکمهٔ «نصب برنامه» در بخش تنظیمات، اگر مرورگر آن را ارائه کند، نمایش داده می‌شود. در غیر این صورت از منوی Chrome گزینهٔ «نصب برنامه» یا «افزودن به صفحهٔ اصلی» را انتخاب کن.
4. پس از نصب و بازکردن آیکون Matchday، نوار آدرس مرورگر نمایش داده نمی‌شود؛ مرورگرهای سازگار از حالت تمام‌صفحه و در غیر این صورت از حالت standalone استفاده می‌کنند.

## نکته دربارهٔ داده‌ها
نتایج زنده، اخبار، تصاویر و آمار همچنان به اتصال اینترنت و در دسترس بودن سرویس‌های بیرونی وابسته‌اند. Service Worker فقط پوستهٔ خود برنامه را برای بازشدن آفلاین نگه می‌دارد و عمداً نتایج زنده را کش نمی‌کند تا اطلاعات قدیمی به جای نتیجهٔ تازه نمایش داده نشود.
